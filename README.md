# credit-card-fraud-analysis

## Problem
Analyze credit card data to identify fraud patterns and risk factors.

## Tools
SQL, Power BI

## Approach
- Cleaned and transformed data using SQL
- Created fraud flag and performed analysis
- Built interactive Power BI dashboard

## Key Insights
- Identified high-risk card types contributing to fraud
- Analyzed impact of credit limits on fraud occurrence
- Observed fraud patterns across different card brands
